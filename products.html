Sinkronizimi me Sinclair

Opsioni më i mirë për GitHub Pages

GitHub Pages është statik, prandaj produktet duhet të lexohen nga një JSON në repo. Nëse Sinclair ose distributori jep API/CSV/JSON zyrtar, GitHub Action mund ta marrë atë dhe ta përditësojë automatikisht data/products.json.

Si përdoret tani?

Ndrysho data/products.json dhe produktet shfaqen automatikisht në këtë faqe. Për sinkronizim automatik, vendos një URL zyrtare në secret SINCLAIR_PRODUCTS_URL në GitHub.
